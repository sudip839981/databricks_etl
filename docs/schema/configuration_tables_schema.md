Note: The `config` schema/database needs to be created manually in Unity Catalog. These tables will reside within that schema. For fields like `ConnectionDetails`, sensitive information (credentials, keys) should reference secrets stored in Azure Key Vault, and the value in the config table should be the secret name or identifier, not the actual secret.

For `DataSourceID`, using a UUID generated by the application/notebook that inserts into this table is recommended over an auto-incrementing integer for better distributed generation and uniqueness.

-- =================================================================================================
-- Configuration Tables Schema for Azure Databricks ETL Framework
-- =================================================================================================

-- -------------------------------------------------------------------------------------------------
-- DataSources Table
-- Stores information about the various source systems.
-- -------------------------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS config.DataSources (
    DataSourceID STRING NOT NULL COMMENT 'Unique identifier for the data source (UUID recommended)',
    SourceName STRING NOT NULL COMMENT 'User-friendly name for the data source (e.g., "ADLS Raw Zone", "OnPrem HR SQL")',
    SourceType STRING NOT NULL COMMENT 'Type of the data source (e.g., "ADLS_GEN2", "SQL_SERVER", "API", "FTP")',
    ConnectionDetails STRING COMMENT 'JSON string containing connection parameters specific to the SourceType',
    Description STRING COMMENT 'Optional description of the data source',
    CreatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of creation',
    UpdatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of last update',
    CONSTRAINT pk_DataSources PRIMARY KEY (DataSourceID)
);

For `DatasetID`, using a UUID is recommended.
For `SourceIdentifier`, the structure of the `SourceIdentifier` JSON will vary based on `DataSource.SourceType`. The ETL notebooks will need to parse this accordingly.

-- -------------------------------------------------------------------------------------------------
-- Datasets Table
-- Stores metadata for each dataset to be processed.
-- -------------------------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS config.Datasets (
    DatasetID STRING NOT NULL COMMENT 'Unique identifier for the dataset (UUID recommended)',
    DatasetName STRING NOT NULL COMMENT 'User-friendly and unique name for the dataset',
    DataSourceID STRING NOT NULL COMMENT 'Foreign key referencing DataSources.DataSourceID',
    SourceIdentifier STRING NOT NULL COMMENT 'JSON string specifying the data object at the source (e.g., file path, table name, API endpoint)',
    DatasetFormat STRING NOT NULL COMMENT 'Format of the source data (e.g., "CSV", "PARQUET", "JSON", "EXCEL", "DELTA")',
    FormatOptions STRING COMMENT 'JSON string for format-specific options (e.g., delimiter for CSV, sheetName for Excel)',
    Description STRING COMMENT 'Optional description of the dataset',
    Owner STRING COMMENT 'Business or technical owner of the dataset',
    SensitivityLevel STRING DEFAULT 'Non-PII' COMMENT 'Data sensitivity level (e.g., "PII", "Confidential", "Public")',
    BronzeLayerSchema STRING COMMENT 'Optional: JSON string defining the expected schema in the Bronze layer (e.g., for validation or initial DDL)',
    BronzeLayerTargetTableName STRING COMMENT 'Name of the target table in the Bronze layer (e.g., brz_mydata)',
    SilverLayerTargetTableName STRING COMMENT 'Name of the target table in the Silver layer after basic cleansing and transformations',
    GoldLayerTargetTableName STRING COMMENT 'Name of the target table in the Gold layer after business aggregations (if applicable)',
    IsEnabled BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'Flag to enable/disable processing for this dataset',
    CreatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of creation',
    UpdatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of last update',
    CONSTRAINT pk_Datasets PRIMARY KEY (DatasetID),
    CONSTRAINT fk_Datasets_DataSources FOREIGN KEY (DataSourceID) REFERENCES config.DataSources(DataSourceID),
    CONSTRAINT uq_DatasetName UNIQUE (DatasetName)
);

For `ColumnID`, using a UUID is recommended.
For `TransformationLogic`, the `TransformationLogic` field can store simple commands or SQL expressions. For very complex transformations, it might reference named UDFs or logic embedded within specific notebooks. The ETL process will need a robust way to interpret and apply these.

-- -------------------------------------------------------------------------------------------------
-- ColumnMetadata Table
-- Stores column-level metadata, including transformations and DQM rule associations.
-- -------------------------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS config.ColumnMetadata (
    ColumnID STRING NOT NULL COMMENT 'Unique identifier for the column metadata entry (UUID recommended)',
    DatasetID STRING NOT NULL COMMENT 'Foreign key referencing Datasets.DatasetID, identifying which dataset this column belongs to',
    SourceColumnName STRING NOT NULL COMMENT 'Name of the column as it appears in the source',
    TargetColumnName STRING NOT NULL COMMENT 'Name of the column in the target (e.g., Silver layer table)',
    DataType STRING NOT NULL COMMENT 'Target data type for the column (e.g., "STRING", "INT", "DECIMAL(10,2)", "TIMESTAMP")',
    Description STRING COMMENT 'Description of the column and its purpose',
    TransformationLogic STRING COMMENT 'Describes the transformation (e.g., "TRIM", "UPPER", SQL expression, or UDF reference)',
    DQMRuleIDs ARRAY<STRING> COMMENT 'Array of DQMRuleIDs (from DQMRules table) to be applied to this column',
    IsPII BOOLEAN NOT NULL DEFAULT FALSE COMMENT 'Flag indicating if the column contains Personally Identifiable Information',
    IsNullable BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'Whether the column can contain null values in the target',
    DefaultValue STRING COMMENT 'Default value to be used if the source column is null (after transformation)',
    DataLength INT COMMENT 'For string types, the maximum expected length',
    Precision INT COMMENT 'For decimal/numeric types, the precision',
    Scale INT COMMENT 'For decimal/numeric types, the scale',
    SourceOrdinalPosition INT COMMENT 'Original position of the column in the source file/table (if applicable)',
    TargetOrdinalPosition INT COMMENT 'Desired position of the column in the target table',
    IsEnabled BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'Flag to enable/disable processing for this column mapping',
    CreatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of creation',
    UpdatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of last update',
    CONSTRAINT pk_ColumnMetadata PRIMARY KEY (ColumnID),
    CONSTRAINT fk_ColumnMetadata_Datasets FOREIGN KEY (DatasetID) REFERENCES config.Datasets(DatasetID)
);

For `DQMRuleID`, using a UUID is recommended.
For `RuleConfiguration`, the `RuleConfiguration` JSON structure is dependent on `RuleType`. The DQM processing logic in notebooks will need to parse this dynamically. For `CUSTOM_SQL_EXPRESSION`, the expression should be written such that it can be injected into a WHERE clause or a CASE statement, using a placeholder like `{{column_value}}` for the actual value of the column being checked.

-- -------------------------------------------------------------------------------------------------
-- DQMRules Table
-- Stores definitions for Data Quality Management rules that can be applied to columns.
-- -------------------------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS config.DQMRules (
    DQMRuleID STRING NOT NULL COMMENT 'Unique identifier for the DQM rule (UUID recommended)',
    RuleName STRING NOT NULL COMMENT 'User-friendly and unique name for the DQM rule',
    RuleType STRING NOT NULL COMMENT 'Type of DQM rule (e.g., "NOT_NULL", "REGEX", "RANGE", "LOOKUP", "CUSTOM_SQL_EXPRESSION")',
    RuleConfiguration STRING NOT NULL COMMENT 'JSON string containing parameters specific to the RuleType',
    Description STRING COMMENT 'Description of the DQM rule and what it checks',
    SeverityLevel STRING NOT NULL DEFAULT 'Warning' COMMENT 'Severity if the rule fails (e.g., "Error", "Warning", "Info")',
    ErrorMessage STRING COMMENT 'A template for the error message if the rule fails. Can use placeholders.',
    IsEnabled BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'Flag to enable/disable this rule',
    CreatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of creation',
    UpdatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of last update',
    CONSTRAINT pk_DQMRules PRIMARY KEY (DQMRuleID),
    CONSTRAINT uq_RuleName UNIQUE (RuleName)
);

For `PipelineID`, using a UUID is recommended.
For `ScheduleCronExpression`, the `ScheduleCronExpression` will be used to configure the schedule of the corresponding Databricks Workflow. The framework will need a component to create/update workflows based on this metadata.

-- -------------------------------------------------------------------------------------------------
-- Pipelines Table
-- Defines ETL pipelines, which group datasets for orchestrated execution (Databricks Workflows).
-- -------------------------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS config.Pipelines (
    PipelineID STRING NOT NULL COMMENT 'Unique identifier for the pipeline (UUID recommended)',
    PipelineName STRING NOT NULL COMMENT 'User-friendly and unique name for the pipeline',
    Description STRING COMMENT 'Optional description of the pipeline''s purpose and scope',
    ScheduleCronExpression STRING COMMENT 'Cron expression for scheduling the pipeline (e.g., "0 0 5 * * ?"). NULL for manual trigger.',
    Parameters STRING COMMENT 'JSON string for pipeline-level parameters (e.g., {"processing_date": "runtime_value"})',
    RunParallel BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'If datasets within this pipeline can be processed in parallel in the workflow',
    Owner STRING COMMENT 'Business or technical owner of the pipeline',
    IsEnabled BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'Flag to enable/disable this pipeline',
    CreatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of creation',
    UpdatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of last update',
    CONSTRAINT pk_Pipelines PRIMARY KEY (PipelineID),
    CONSTRAINT uq_PipelineName UNIQUE (PipelineName)
);

For `DatasetPipelineMappingID`, using a UUID is recommended.
For `ProcessingOrder`, if `Pipelines.RunParallel` is true for the parent pipeline, `ProcessingOrder` might be used for logical grouping or ignored. If `Pipelines.RunParallel` is false, this field dictates the sequence of notebook execution for the datasets within that pipeline.

-- -------------------------------------------------------------------------------------------------
-- DatasetPipelineMapping Table
-- Maps datasets to pipelines, defining the sequence and specific parameters for processing.
-- -------------------------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS config.DatasetPipelineMapping (
    DatasetPipelineMappingID STRING NOT NULL COMMENT 'Unique identifier for this mapping entry (UUID recommended)',
    PipelineID STRING NOT NULL COMMENT 'Foreign key referencing Pipelines.PipelineID',
    DatasetID STRING NOT NULL COMMENT 'Foreign key referencing Datasets.DatasetID',
    ProcessingOrder INT NOT NULL DEFAULT 0 COMMENT 'Order of execution for datasets within a pipeline if sequential. Lower numbers first.',
    BronzeParameters STRING COMMENT 'JSON string for specific parameters to the Bronze notebook for this dataset in this pipeline',
    SilverParameters STRING COMMENT 'JSON string for specific parameters to the Silver notebook for this dataset in this pipeline',
    GoldParameters STRING COMMENT 'JSON string for specific parameters to the Gold notebook for this dataset in this pipeline',
    IsEnabled BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'Flag to enable/disable this dataset''s processing within this pipeline',
    CreatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of creation',
    UpdatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of last update',
    CONSTRAINT pk_DatasetPipelineMapping PRIMARY KEY (DatasetPipelineMappingID),
    CONSTRAINT fk_DatasetPipelineMapping_Pipelines FOREIGN KEY (PipelineID) REFERENCES config.Pipelines(PipelineID),
    CONSTRAINT fk_DatasetPipelineMapping_Datasets FOREIGN KEY (DatasetID) REFERENCES config.Datasets(DatasetID),
    CONSTRAINT uq_PipelineDataset UNIQUE (PipelineID, DatasetID) -- Ensures a dataset is mapped only once to a given pipeline
);

For `NotificationID`, using a UUID is recommended.
For `MessageTemplate`, the `MessageTemplate` can be quite rich, potentially HTML for emails. The notification utility will need to handle placeholder replacement (e.g., using Python's `string.Template` or f-strings if generated dynamically).

-- -------------------------------------------------------------------------------------------------
-- Notifications Table
-- Configures notifications for pipeline events.
-- -------------------------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS config.Notifications (
    NotificationID STRING NOT NULL COMMENT 'Unique identifier for the notification configuration (UUID recommended)',
    PipelineID STRING COMMENT 'Foreign key referencing Pipelines.PipelineID. If NULL, could be a global default (less common).',
    NotificationType STRING NOT NULL COMMENT 'Type of notification (e.g., "EMAIL", "WEBHOOK", "SLACK", "TEAMS")',
    Recipient STRING NOT NULL COMMENT 'Target for the notification (e.g., email address, webhook URL, channel name)',
    TriggerEvent STRING NOT NULL COMMENT 'When to send the notification (e.g., "OnSuccess", "OnFailure", "OnStart", "OnDQMWarning")',
    SubjectTemplate STRING COMMENT 'Template for the notification subject. Placeholders like {PipelineName} can be used.',
    MessageTemplate STRING COMMENT 'Template for the notification body. Placeholders like {PipelineName}, {ErrorMessage} can be used.',
    IsEnabled BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'Flag to enable/disable this notification',
    CreatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of creation',
    UpdatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of last update',
    CONSTRAINT pk_Notifications PRIMARY KEY (NotificationID),
    CONSTRAINT fk_Notifications_Pipelines FOREIGN KEY (PipelineID) REFERENCES config.Pipelines(PipelineID)
);

For `OutputDestinationID`, using a UUID is recommended.
For `DestinationDetails`, the `DestinationDetails` JSON structure will vary based on `DestinationType`. The output writing notebooks will need to parse this and handle different types of sinks, including options like write mode (overwrite/append) and format (Parquet, Delta, CSV) for file-based outputs.

-- -------------------------------------------------------------------------------------------------
-- OutputDestinations Table
-- Configures where processed data from different layers should be written.
-- -------------------------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS config.OutputDestinations (
    OutputDestinationID STRING NOT NULL COMMENT 'Unique identifier for the output destination (UUID recommended)',
    DatasetID STRING NOT NULL COMMENT 'Foreign key referencing Datasets.DatasetID, identifying the source dataset',
    PipelineID STRING COMMENT 'Optional: Foreign key referencing Pipelines.PipelineID, if output is pipeline-specific',
    OutputLayer STRING NOT NULL COMMENT 'The layer from which data is being output (e.g., "Bronze", "Silver", "Gold")',
    DestinationType STRING NOT NULL COMMENT 'Type of destination (e.g., "UNITY_CATALOG_TABLE", "ADLS_GEN2_PATH")',
    DestinationDetails STRING NOT NULL COMMENT 'JSON string containing details specific to the DestinationType',
    Description STRING COMMENT 'Optional description of this output',
    IsEnabled BOOLEAN NOT NULL DEFAULT TRUE COMMENT 'Flag to enable/disable writing to this destination',
    CreatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of creation',
    UpdatedAt TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'Timestamp of last update',
    CONSTRAINT pk_OutputDestinations PRIMARY KEY (OutputDestinationID),
    CONSTRAINT fk_OutputDestinations_Datasets FOREIGN KEY (DatasetID) REFERENCES config.Datasets(DatasetID),
    CONSTRAINT fk_OutputDestinations_Pipelines FOREIGN KEY (PipelineID) REFERENCES config.Pipelines(PipelineID)
);
